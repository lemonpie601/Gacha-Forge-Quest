# 가챠 포지 퀘스트 확장

**Gacha Forge Quest Extension** · Marinara Engine 개인 확장 · v0.14.1 (로컬 수정)

> 원본: [tlsiddl/Gacha-Forge-Quest-Extension](https://github.com/tlsiddl/Gacha-Forge-Quest-Extension) v0.11.0을 고친 버전입니다.
> 0.14.1 변경: 이미 진행 중인 월드에 업데이트해도 바로 반영됩니다. 확장이 켜지면 저장된 스토리를 다시 읽어 예전 버전이 놓친 날짜·시각 표시를 채우고, 날짜나 시작 소지금이 비어 있으면 월드마다 한 번 세계관에 맞춰 정합니다. 새 챕터를 기다리거나 전체 재분석을 할 필요가 없습니다.
>
> 0.14.0 변경: 시작 소지금을 직접 입력하지 않았으면 세계관 로어북과 스토리를 보고 정합니다. 로어북이나 원문에 금액이 적혀 있으면 그 금액을 씁니다. 아래 [시작 소지금](#시작-소지금)을 보세요.
>
> 0.13.0 변경: 세계관 시계. 원문에 날짜가 없으면 세계관에 맞는 날짜를 정해 두고, 시각·때(아침·저녁 등)를 따라갑니다. `4월 9일`, `3일차`, `제국력 312년` 같은 표기와 `[밤]`, `오후 3시` 같은 시각 줄도 읽습니다. 자세한 내용은 아래 [세계관 시계](#세계관-시계)를 보세요.
>
> 0.12.0 변경: 전체화면에서 팝업·확인창이 동작하도록 수정, 기기 간 동기화 오류(월드 이름 섞임·수정 내용 사라짐) 수정, 게임 화면의 챕터 인식(“Chapter Three”) 수정, 자동 반영이 안 된 항목을 팝업에서 처리, 소지품 중복 방지·[사용]·착용 상태 로어북 반영, 깨진 갤러리 그림 복구, 휴대폰 화면 배치 개선, 업적 기능 제거.

가챠 포지에서 진행하는 이야기를 **퀘스트, 보상, 자산, 장비, 인물, 장소, 일정**으로 정리하는 기록 보조 확장입니다. 스토리에서 확인된 사건을 AI로 분석하고, 원문 근거를 검토해 각 월드의 기록에 반영할 수 있습니다.

> 비공식 개인 프로젝트입니다. 가챠 포지의 공식 기능이나 게임 내 보상 지급 시스템을 대체하지 않으며, 실제 게임 데이터 및 능력치를 임의로 수정하지 않습니다.

## 주요 기능

| 영역 | 할 수 있는 일 |
| --- | --- |
| **퀘스트** | 의뢰·목표·완료 상태 관리, 상위·하위 퀘스트 연결, AI 연결 검토, 선택·분기 이력 |
| **보상 수령함** | 지급 예정·수령·적용 상태 조회, 거래 및 소지품 기록과 연결 |
| **자산·거래** | 입금·미수금·예정 지급·지출 구분, 계약 금액과 실제 수령액 구별, 관련 변경 기록 |
| **소지품·장비** | 보유/수령 예정 구분, 장비 종류·착용 부위·옵션, 착용/해제, 제작부터 수령까지의 이력 |
| **장비 강화** | 스토리에 근거가 있는 옵션 추가·교체, 강화 전후 변경 이력, 장비 도감 |
| **세계관 일정** | 스토리의 날짜·시각·예정일 정리, 날짜가 없는 세계관은 어울리는 날짜를 정해 이어 감, 기한이 지났지만 완료되지 않은 항목 확인 |
| **인물·장소·업적** | 월드에서 확인된 인물과 장소, 활동 및 업적 관련 기록 |
| **AI 스토리 분석** | 저장된 챕터·장면에서 사건 후보를 추출하고 원문 근거와 비교 |
| **로어북 연동** | 별도 로어북으로 현재 기록 요약 반영 지원(엔진 권한·설정에 따라 제한) |
| **백업·복원** | JSON 수동 백업, 저장 공간에 따른 제한적 로컬 자동 복원 지점 |

월드별 기록은 분리되며, AI가 모든 판단을 무조건 확정하지 않도록 **검토·승인 흐름**을 제공합니다.

## 설치

### 준비물

- **Marinara Engine**와 **Gacha Forge**
- **GitHub 확장 관리자** 개인 확장
- AI 분석을 사용하려면 Marinara에 설정된 **AI 연결**

### GitHub 링크로 설치하기

1. Marinara에서 **GitHub 확장 관리자**를 엽니다.
2. 저장소 추가 또는 GitHub 링크 등록 기능에 아래 주소를 입력합니다.

   ```text
   https://github.com/lemonpie601/Gacha-Forge-Quest
   ```

3. GitHub 확장 관리자에서 해당 확장을 **설치·활성화**합니다.
4. **Gacha Forge** 화면으로 이동해 상단바에 **퀘스트 아이콘**이 표시되는지 확인합니다.

설치 후 새 버전이 올라오면 GitHub 확장 관리자에서 해당 저장소의 **업데이트 기능**을 이용해 주세요.

> ZIP 파일을 직접 다운로드하거나 다시 압축할 필요는 없습니다. 관리자 버전에 따라 버튼 이름이 다를 수 있습니다. 업데이트된 확장은 비활성 상태로 저장되니, 마리나라에서 새 코드를 확인하고 다시 켜 주세요. 기존 기록과 설정은 그대로 남습니다.

## 처음 사용하는 방법

1. **퀘스트 아이콘**을 열고 현재 가챠 포지 월드가 올바르게 선택됐는지 확인합니다.
2. 직접 퀘스트·소지품을 등록하거나 저장된 스토리를 바탕으로 **AI 분석**을 실행합니다.
3. AI가 제시한 사건과 **원문 근거**를 검토합니다. 실제로 발생한 사건만 승인하세요.
4. 자산의 **지급 약속**과 **입금 완료**, 장비의 **수령 예정**과 **실제 보유**를 구분해 확인합니다.
5. 중요한 작업 전에는 **설정 → 백업 내보내기**로 JSON 파일을 보관하세요.

### 장비 옵션 사용 예시

`소지품 → 물품 선택 → 물품 종류 지정`에서 무기·방어구·장신구·도구 등을 지정하면 장비 옵션과 착용 상태를 관리할 수 있습니다.

- **제작 의뢰:** 수령 예정 장비로 기록
- **옵션 확인:** AI가 스토리 원문에 적힌 효과를 추출하여 검토
- **제작 완료·수령:** 근거가 확인되면 기존 장비 기록에 이력을 누적
- **강화·개조:** 교체 근거가 확인된 경우 강화 전후 옵션을 구분
- **착용·해제:** 실제 보유 중인 장비를 사용자가 선택

장비 옵션은 **기록용 정보**입니다. 게임 내 전투 능력치가 자동으로 변하지 않습니다.

## AI 분석과 자동화에 관한 안내

- AI 분석에는 **Marinara에 등록된 AI 연결**을 사용합니다. 모델 공급자에 따라 비용이 발생할 수 있습니다.
- 원문이 불명확하거나 여러 장비·계약이 비슷한 경우, 자동 연결이나 확정에 실패할 수 있습니다.
- **AI 선택 검토**는 스토리에서 실제 선택 후보를 찾아 제안합니다. 새 퀘스트 생성이나 목표 변경을 무조건 자동 실행하지 않습니다.
- 제작 예정일·입금 예정일이 도달해도 그 자체로 **제작 완료·수령·입금**으로 판정하지 않습니다.
- 옵션의 변경·교체는 인용문에 근거하므로, 복잡한 서술에서는 사용자 확인이 필요합니다.
- 자동 분석 및 자동 적용 옵션은 사용 전 기록이 의도대로 반영되는지 확인하는 것을 권장합니다.

## 데이터와 백업

- 기본 기록은 브라우저의 `localStorage` 키 **`gf-quest-v1`**에 저장됩니다.
- **다른 기기와 동기화(v0.11.0):** 같은 기록을 마리나라 서버의 확장 전용 저장소(`marinara.storage`, 확장당 1,000,000바이트)에도 gzip으로 압축해 보관합니다. 편집하고 몇 초 뒤(최소 20초 간격) 올리고, 확장을 켤 때·화면으로 돌아올 때·창을 열 때 받아 옵니다. 주기적으로 계속 확인하는 타이머는 없습니다.
- 이 기기에 새 변경이 없으면 서버 기록을 그대로 받고, 두 기기 모두 바뀌었으면 월드별로 합칩니다(같은 게임 월드는 게임 월드 ID로 판단, 더 늦게 고친 쪽 유지). 합치기 직전 이 기기 기록은 따로 보관되며 설정 탭에서 되돌릴 수 있습니다.
- 지금 보고 있는 월드 선택은 기기마다 따로 둡니다. 설정 탭에서 기기별로 동기화를 끄거나 바로 동기화할 수 있습니다.
- 압축한 기록이 서버 한도를 넘으면 올리지 않고 알려 드립니다. 저장 공간 정리로 줄여 주세요. 같은 월드를 두 기기에서 동시에 고치면 더 늦게 고친 쪽이 남습니다.
- 마리나라 서버 주소가 같아야 같은 저장소를 씁니다. 확장을 지우고 다시 설치하면 서버 저장소가 새로 시작될 수 있으니 백업을 권합니다.
- 설정에서 **JSON 백업 내보내기·가져오기**를 사용할 수 있습니다.
- 자동 복원 지점은 저장 공간과 기록 크기에 따라 **최대 2개**까지 보관하며, 보관되지 않을 수도 있습니다. 중요한 기록은 반드시 별도로 백업하세요.

## 호환성 및 주의사항

- Marinara Engine **2.5.0 기반 환경**을 중심으로 작성되었습니다. 다른 버전에서의 호환성은 보장하지 않습니다.
- 가챠 포지 및 다른 개인 확장과 함께 사용하는 환경은 설치 상태에 따라 다를 수 있습니다.
- 개인 확장 특성상 브라우저 저장소와 엔진 API 권한의 영향을 받습니다.
- 이 저장소의 코드에 대한 정적 검사와 일부 기능별 검사는 진행했지만, **모든 AI 모델·브라우저·기기에서 완전한 통합 테스트를 마친 것은 아닙니다**.

## 세계관 시계

v0.13.0부터 날짜와 함께 그날의 시각·때를 기록합니다.

**날짜를 읽는 곳**

- 날짜만 적힌 줄: `2033-04-09`, `[2033년 4월 10일 (목)] 오후 3시`, `제국력 312년 4월 9일`
- 연도 없는 날짜 줄: `4월 11일 (금) 아침` (지금 연도를 따르고, 해가 바뀌면 다음 해로 넘깁니다)
- 날짜 순번 줄: `3일차`, `DAY 3`, `D+2`
- 시각 줄: `오후 3시 20분`, `[밤]`, `— 새벽 —`
- AI 분석: 원문에 적힌 날짜, `다음 날 아침` 같은 날 바뀜, 그리고 마지막 장면의 시각이나 때(해가 지는 묘사 등). 근거 문장에 실제로 적혀 있어야 받아들입니다.

시각이 앞으로 돌아가면(밤 → 아침) 다음 날로 봅니다. 하루의 경계는 새벽 4시라서 `밤 → 새벽 2시`는 같은 밤으로 칩니다.

**날짜가 전혀 없는 세계관**

원문에 날짜가 한 번도 안 나오면 분석할 때 AI에게 세계관(시대·계절·배경)에 어울리는 날짜를 하나 정하게 합니다. 원문에 `2033년` 같은 연도가 있으면 AI가 다른 연도를 골라도 원문 연도를 씁니다. AI 응답이 없으면 원문의 연도와 계절 묘사(벚꽃, 장마, 단풍, 눈)로 정합니다. 프로필의 **세계관에 맞게 날짜 정하기** 버튼으로 직접 실행할 수도 있습니다.

이렇게 정한 날짜는 '세계관 추정'으로 표시되고, 원문에 처음으로 날짜가 나오거나 직접 입력하면 그 날짜에 맞춰 지금까지의 추정 날짜를 한꺼번에 옮깁니다. 추정 날짜로 계산한 약속이 엉뚱하게 '기한 지남'으로 뜨지 않게 하기 위해서입니다.

**프로필의 날짜 버튼**

| 버튼 | 하는 일 |
| --- | --- |
| 날짜·시각 입력 | `2033-04-08 오후 3시`, `4월 9일 저녁`, `오후 6시`처럼 날짜나 시각, 또는 둘 다 입력 |
| 시간 경과 | 새벽 → 아침 → 오전 → 점심 → 오후 → 저녁 → 밤 → 심야 순서로 한 단계, 심야 다음은 다음 날 새벽 |
| 하루 경과 | 날짜 +1 |
| 세계관에 맞게 날짜 정하기 | 날짜가 없거나 추정 날짜일 때만 보입니다 |

**로어북 반영**

요약 항목에 `시각` 줄이 추가됩니다. 설정의 로어북 카드에서 **장면이 바뀔 때 날짜·시각 한 줄을 적도록 요청**을 켜면, 가챠 포지가 장면 첫 줄에 날짜·시각을 적도록 안내해 확장이 날짜를 더 정확히 따라갑니다. 이야기 문체에 한 줄이 더해지므로 기본값은 꺼짐입니다.

달력에서는 `금일 오후 6시`처럼 시각이 있는 약속에 시각을 붙여 보여 주고, 오늘 그 시각이 지났는데 확인되지 않은 약속은 기한 지남으로 표시합니다.

## 시작 소지금

프로필의 소지금은 `시작 소지금 + 입금 확인 − 지출`로 계산합니다. v0.14.0부터 시작 소지금을 직접 넣지 않아도 됩니다.

- **처음 분석할 때 한 번** AI에게 세계관 로어북(가챠 포지 월드·인물 로어북 중 켜진 항목), 줄거리, 최근 장면을 보여 주고 시작 소지금을 정하게 합니다. 날짜가 아직 없으면 같은 호출에서 날짜도 함께 정합니다.
- 로어북이나 원문에 `소지금 35만 원`처럼 금액이 적혀 있으면 그 금액을 씁니다. 인용한 문장에 그 금액이 실제로 있을 때만 '원문 금액'으로 표시합니다.
- 금액 단서가 없으면 주인공의 신분·직업·처지와 세계관 물가에 맞춰 정하고 '세계관 추정'으로 표시합니다.
- AI 응답이 없으면 `지갑`, `잔고`, `소지금` 옆에 적힌 금액을 찾고, 그것도 없으면 화폐별 기본값(예: 30만 원, 100골드, 5냥)을 씁니다.
- 거래 내역이 비어 있고 로어북이 다른 화폐(골드 등)를 쓰면 그 화폐를 이 월드의 주 화폐로 정합니다.

프로필의 **세계관에 맞게 정하기 / 다시 정하기**로 언제든 다시 고를 수 있고, **시작 금액 고치기**로 직접 입력한 금액은 자동으로 덮어쓰지 않습니다.

## 모바일 화면

가챠 포지는 가로 화면만 지원하므로, 휴대폰은 가로 화면 기준으로 맞춥니다(v0.10.5). 위쪽 메뉴는 각 테마 고유의 모바일 탭 모양(현대·동양·판타지·SF·학원·일상)을 그대로 쓰고 높이만 줄였습니다. v0.10.3~0.10.4에서 모든 테마의 메뉴 버튼을 같은 흰 칸·남색으로 강제로 칠하던 부분은 없앴습니다. 화면 제목과 월드 선택은 한 줄에 놓고, 퀘스트 탭은 왼쪽 목록·오른쪽 상세의 두 칸으로 보여 줍니다. 본문은 위아래로 스와이프해 스크롤합니다. 세로 화면과 좁은 화면에서는 이전처럼 한 칸으로 쌓입니다. 실제 기기·브라우저별 동작은 환경에 따라 다를 수 있습니다.

## 문제 해결

**퀘스트 아이콘이 보이지 않아요.** 확장을 활성화했는지, Gacha Forge 화면에 진입했는지 확인한 뒤 새로고침해 보세요.

**AI 분석이 실패해요.** 설정에서 AI 연결을 선택했는지, 해당 연결이 Marinara에서 정상 작동하는지 확인하세요. 모델 응답 형식이 예상과 다르면 일부 분석이 거절될 수 있습니다.

**장비 옵션이 자동으로 안 들어와요.** 옵션이 적힌 장면이 분석 대상에 포함되어 있는지, 원문 근거가 확인되는지, 해당 제안을 승인했는지 확인하세요.

**저장된 기록이 사라졌어요.** 접속 도메인·브라우저가 달라졌는지 먼저 확인하세요. 다른 저장소에는 기록이 자동으로 복제되지 않습니다. 기존에 보관한 JSON 백업이 있다면 가져올 수 있습니다.
